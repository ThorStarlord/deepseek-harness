# Agent Note: One-time agent-assisted design review for PR #53

Status: implemented

[English](2026-11-23-pr53-agent-assisted-design-review-exception.md) | 中文

## Problem

PR #53 增加了用户可见的 Activity Strategic Brief 交互，因此通常需要按照现行政策取得独立的人类产品或设计审查。所有者希望在保留技术资格审查和真实主张的同时减少必要的人类参与，并将是否采用 PR #53 一次性例外的决定委托给协调 agent。本记录仅将该授权用于此 PR 的具体选择。

## Decision

本仓库在此政策变更集成后，仅对 PR #53 采用一次性例外。必须在彼此独立的 agent 上下文中完成两份只读 coding-agent 评估：一份评估技术和安全，另一份评估产品和设计；后者提供产品或设计处置。审查者不得实现或实质性塑造候选版本；两者不得在完成评估前共享草稿发现，必须审查同一个最终 PR 提交。每份记录必须说明不同的审查任务、可获得的模型信息、角色、提交、证据、发现、处置和限制。产品或设计审查者检查组装后的 Web 交互。技术或安全审查者检查授权、持久化、取消与恢复、仓库身份和修订号以及意外执行风险。相关的行为、持久化和恢复定向检查必须通过，且不得留有阻塞发现。

PR 必须说明两份评估由 agent 完成，并非人类批准。其验收主张限于有关请求处理、持久化、归属、组装后的 Web 显示和跨 Session 恢复的确定性证据。除非直接真实提供商证据能够证明，否则真实模型战略评估成功与比较性战略效果仍未验证。缺少该证据不能使这两项主张获得资格。

此例外仅适用于 PR #53，且仅在政策变更集成后生效。它不会延长已到期的 Stage 1 例外，也不会为其他 PR 建立先例。身份验证、授权、凭证处理、仓库权限、原生提供商控制、受保护的状态转换、安全审查权限及合并权限均保持不变。评估后若发生实质性变更，必须针对后续提交重新执行受影响的检查和评估。

协调者于 2026-11-23 根据所有者的明确授权采纳了这项具体例外。本记录说明这是依据授权作出的政策决定，不声称所有者亲自审阅了确切文本，也不声称 agent 评估等同于人类批准。

## Alternatives considered

**保留人类审查要求并让 PR #53 保持开放。** 这保留了人类产品判断，但会让这个有用的建议能力继续依赖所有者希望在此 PR 中免于强制要求的审查者。

**恢复或扩大已到期的 Stage 1 例外。** 这会影响无关或未来的改动，超出此次授权的一次性范围。

**只缩小功能主张而不更改审查规则。** 这可以正确限制确定性证据能证明的内容，但无法满足用户可见交互所需的独立人类产品或设计处置。

## Consequences

PR #53 可以获得有记录的独立 agent 辅助处置，同时不宣称已经证明真实提供商的效果。该流程仍要求审查确切提交、检查组装后的 Web、提供相关行为和恢复证据，并解决所有阻塞发现。本次 PR 将失去独立的人类产品或设计判断；模型评估可能会遗漏人类审查者会注意到的可用性问题。其他 PR 仍须遵循通常的人类审查政策。
