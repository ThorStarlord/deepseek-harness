# Agent Note: Stage 1 风险比例产品评审

Status: implemented

[English](2026-11-15-stage1-risk-proportionate-product-review.md) | 中文

## 问题

仓库要求对用户可明显感知的交互变更进行合格的独立人工产品/设计评审。所有者已授权的 Home Harness Stage 1 待办没有固定的独立评审者池，无法保证每次集成都有可用的评审者；与此同时，各票据保留了明确的用户意图、现有权限和有界行为。如果每项交互都必须经过人工评审，即使能够通过直接交互证据和针对性验证来评估风险，也会阻塞这批已授权工作。

## 决策

对于所有者授权的 Home Harness Stage 1 待办——Issue #17 至 #30——可由单独的只读 Agent 评估低风险或中等风险变更，作为人工产品/设计评审的所有者授权替代方式。这是对该指定范围内人工评审要求的例外，不属于独立人工评审、人工批准或 **APPROVE** 结论。集成 Issue #30 后，本例外到期，不适用于其他工作。

只有在评估确认以下条件全部满足时才能使用替代方式：变更符合已批准票据的范围；不改变身份验证、授权、仓库权限或跨用户身份归属；执行只会在用户明确操作后通过现有 provider 权限语义启动；不会新增自动启动、自动恢复、无界委派、不可逆或超出范围的副作用；并保留现有 Session 和 Activity 事实。只有当存储版本安全、写入失败和重启行为经过测试、回滚及残留记录行为已知，并且缺少编辑或删除等限制已明确说明时，新增的持久 Activity 记录才符合条件。变更中关于执行、权限、验证、验收和历史来源的声明，均须注明支持这些声明的证据。

低风险表示描述性或外观性行为，影响范围极小，不新增持久数据或执行行为。中等风险表示有界、由用户发起的行为，或严格版本化 Activity 存储中的新增数据；不得改写现有数据或改变权限。高风险包括改变身份验证、授权、跨用户隐私、现有持久事实或外部权限；新增自动或无界执行；引入破坏性或不可逆影响；以及缺少直接证据支持的重大完成、验证、验收、历史来源或安全声明。任何未分类或尚未解决的风险都按高风险处理。

评估 Agent 不得实现或实质性设计该变更。它须在新的只读评估中检查完整 Issue 验收标准、PR 的精确差异和 head SHA、直接渲染的交互证据、针对性验证、发现和残余不确定性。每项用户可见交互的 PR 都须提供覆盖实际受影响行为的渲染证据；测试和实现检查可作为辅助，但不能取代该证据。

PR 须记录 **OWNER-AUTHORIZED AGENT ALTERNATE — ELIGIBLE** 或 **HUMAN REVIEW REQUIRED**、评估 Agent 和模型、其与实现工作的隔离情况、Issue 和所评审 SHA、风险理由、检查过的交互和证据、验证、发现及残余不确定性。所有者对 Stage 1 范围的授权涵盖符合条件的 PR，无需逐票据重新批准。资格判断不确定、缺少渲染证据、仍有重大未解决发现或变更风险较高时，必须由合格的独立人工评审者评审。如果没有合格评审者，该 PR 保持未合并状态。

## 考虑过的替代方案

- **每项 Stage 1 交互都由独立人工评审——保留为高风险路径。** 人工评审提供独立的产品/设计判断，高风险或不确定的变更仍须人工评审。如果没有评审者时仍要求每项符合条件的变更都接受人工评审，这批有界且已获授权的工作将被阻塞。
- **将 Agent 评估视作人工批准——拒绝。** 模型评估不等同于合格的人工评审。将其记录为 **APPROVE** 会错误说明判断者身份并削弱问责性。
- **不受限制的所有者或 Agent 例外——拒绝。** 通用替代方式会让仓库内其他工作更容易绕过产品评审。采纳的替代方式仅适用于 Issue #17 至 #30，要求单独评估和直接证据，并将不确定或高风险情况升级给人工评审者。

## 影响

该范围有限的替代方式允许 Stage 1 有界工作继续推进，无需每张票据都重新请求所有者批准。它提供的独立人工判断少于设计师或产品评审者，可能遗漏主观易用性问题。新建的只读评估、明确的风险标准、直接交互证据、针对性测试、已记录的限制，以及对未解决或高风险问题的人工升级，可以降低这类风险，同时不宣称它等同于人工评审。

此替代方式不改变身份验证、权限、provider 授权或票据验收标准。它不会授权执行，也不会启动 Stage 2 或 Stage 3。当没有合格评审者时，高风险工作仍需等待合格的人工评审。

## 验证

UI skill 规定资格条件、评估隔离要求、PR 必须提供的证据、结论类型、适用范围和到期条件。所有者在每个使用替代方式的 PR 中核实这些记录。文档门禁会校验 skill 和双语 Note 格式，但不会机械判断风险资格或验证 Agent 评估。
